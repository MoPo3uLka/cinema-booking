# Cinema Booking — дипломный проект

## Описание
Приложение для бронирования билетов в кинотеатр с административной панелью.

## Стек технологий
- React 18 (Vite)
- React Router 6
- Bootstrap 5
- QRCode.react
- HTML5 Drag & Drop API
- REST API (shfe-diplom.neto-server.ru)

## Запуск локально
1. Установите зависимости:
   npm install
2. Запустите dev-сервер:
   npm run dev
3. Откройте http://localhost:5173

## Деплой
Проект доступен на GitHub Pages: https://mopo3ulka.github.io/cinema-booking/

## Основные возможности
- Просмотр расписания на 6 дней
- Выбор мест в зале
- Бронирование билетов с генерацией QR-кода
- Админ-панель (залы, фильмы, цены, сеансы)
- Drag & Drop для добавления и удаления сеансов
- Адаптивная вёрстка (320–1920px)
